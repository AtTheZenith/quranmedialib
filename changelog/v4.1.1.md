# v4.1.1 — Rich Text Overhaul & Presets Solidification

## Highlights

- **Rich text parser rewritten to the modern tag spec** (`#b|i|bi#<hex6|hex8>#text#`) — legacy format (`#b#Bold#b#`, `#ff0000#Red#ff0000#`) is fully removed
- **Presets solidified** — v3 layout parity restored across all 9 aspect-mode combinations (`landscape`/`story`/`square` × `default`/`arabic`/`translation`)
- **Bold and italic rendering actually applied** — bold was parsed but never drawn; italic ignored the configured italic font path
- **New `ignore_non_token_hashtags` option** — warns on stray `#` not forming a valid tag (default), or silently renders them as literal text while still parsing valid tags
- **332 unit tests pass** (was 322)

## New Features

- `TextConfig.ignore_non_token_hashtags` (`bool`, default `False`) — when `False`, a `#` character not regexed into a rich-text tag logs a `WARNING` that names the malformed tag itself, restates the expected `#<style>#<color>#text#` syntax, and points to `ignore_non_token_hashtags` to suppress it. When `True`, the warning is suppressed and stray hashtags render as literal text; valid tags are still parsed in both modes.
- Pairwise pixel-identity tests guarantee no style silently renders identically to another: normal, bold, italic, and bold-italic are each compared by SHA-256 of their raw pixel bytes and must all be distinct. A dedicated test asserts a pixel exactly matches the tag color.

## Bug Fixes

- **Bold never rendered**: `simulate_bold` was parsed and stored on each styled word but was excluded from the batch styling key, so it was never applied at draw time. The batch style key now includes `simulate_bold`, and `_flush_batch()` applies the stroke simulation.
- **Italic hardcoded the font path**: the italic renderer did `.replace(".ttf", "_italic.ttf")` instead of honoring `config.italic_font_path`. Custom italic fonts are now respected.
- **Legacy rich-text format accepted**: `_RE_RICH_TAG` previously tolerated the old `#style#text#style#` and `#hex#text#hex#` forms. The parser now accepts only the modern, mandatory-closing-tag spec: `#([bi]+)#([0-9a-fA-F]{6}|[0-9a-fA-F]{8})#([^#]+)#`. Six-digit (24-bit) colors gain an opaque `ff` alpha; eight-digit (32-bit) colors are used verbatim.
- **Combined bold+italic** (`bi`) now applies the italic font and stroke simulation together instead of picking one style.
- **Dead code removed**: `_RE_STRIP_TAGS` and associated strip logic removed.
- **Isolation output modernized**: `format_isolation_text()` and `IsolateWordsWorkflow` now emit per-word modern tags (`#b#00000000#word#` for transparent non-target words), and the default highlight style is the gold `#b#ffd700ff#` matching `TextConfig.highlight_color`.

## Presets Solidification

- `presets.py` reworked to restore byte-for-byte v3 layout parity across all 9 aspect-ratio/mode combinations.
- Highlights include: per-aspect-ratio padding in `_v3_content_width()`, block-level centering + v3-compatible Arabic rect for story/square, per-aspect-ratio arabic width, resolution scaling, and `keep_bottom` behavior.
- `Frame` and `VImage` received small alignment corrections; `verse.py` / `verse_range.py` / `isolate_words.py` workflows adapted to the restored layout pipeline.
- Validation coverage extended in `_harness.py` to lock in the 9-combo parity.

## Dev Experience

- **`[dependency-groups] dev` consolidated** to `ruff`, `pytest`, `psutil` — `uv sync` now installs the full dev toolchain (previously `ruff`/`pytest` lived only in the optional `.[dev]` extra, so fresh `uv sync` environments lacked them).
- **Git hooks added** in `.githooks/`, wired via `git config core.hooksPath .githooks`:
  - `commit-msg` — Conventional Commits enforcement (Merge/Revert exempt, `SKIP_QC=1` bypass).
  - `pre-commit` — `ruff check` on staged Python files only.
  - `pre-push` — `ruff check src/ tests/ demo.py` + `quranmedialib.check test --unit`.
- **Pixel validation is developer-local** — CI and the pre-push hook gate on lint + unit tests only, because golden references are not tracked. No forced ref-regeneration commits.
- **GitHub Actions CI** (`.github/workflows/ci.yml`): `uv sync --frozen` → `ruff check` → `check test --unit`, with uv cache and concurrency cancellation.
