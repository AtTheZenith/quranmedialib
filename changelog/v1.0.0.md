# v1.0.0 — Initial Stable Release

Date: 2024-04-05

## What's Changed
- initial project setup with Arabic word-to-image rendering
- word-by-word translation support
- greedy overflow control using Qur'anic stop signs
- arabic text alignment and translation text alignment fixes
- verse number module with color arguments
- glow effect implementation
- framer layout engine with translation and verse positioning
- annotate_words to combine words with same wbw
- rich text formatting and timage module
- isolate_words workflow
- verse workflow, verse_range workflow, surah workflow generators
- presets system
- surface-level API and package registry
- test suite separation and standardization
